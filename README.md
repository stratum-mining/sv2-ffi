# Stratum V2 FFI

C bindings to the [Stratum V2 Reference Implementation (SRI)](https://github.com/stratum-mining/stratum).

A C API over the SRI crates, written by hand as a raw FFI with its header generated by cbindgen, for programs that speak Stratum V2 with SRI's code deciding what the protocol allows. It covers the Noise transport (`codec_sv2`), the subprotocol messages (`common_messages_sv2`, `mining_sv2`, `job_declaration_sv2`, `template_distribution_sv2`) and the mining channels (`channels_sv2`).

Bindings for languages that UniFFI supports (Python, C++) live in [sv2-uniffi](https://github.com/stratum-mining/sv2-uniffi).
